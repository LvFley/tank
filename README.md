# 坦克大战 (Tank Battle)

一个用纯 HTML + Canvas + JavaScript 实现的经典《坦克大战》网页小游戏，单文件即可运行，无需任何依赖。

## 玩法

- 控制绿色坦克，击毁所有红色敌方坦克，保护底部的基地（金色鹰标）。
- 敌方坦克或子弹摧毁基地，或我方生命耗尽，则游戏失败。
- 清空本关敌人即进入下一关，敌人数量逐关递增。

## 操作

| 按键 | 功能 |
| --- | --- |
| `W` `A` `S` `D` / 方向键 | 移动 |
| `空格` / `J` | 射击 |
| `P` | 暂停 / 继续 |
| `R` | 重新开始 |

## 运行

直接用浏览器打开 `index.html` 即可，也可以起一个本地静态服务器：

```bash
python -m http.server 8000
# 然后访问 http://localhost:8000
```

## 结构

- 砖墙 `#`：可被子弹摧毁
- 钢墙 `@`：不可摧毁
- 基地 `%`：被摧毁则游戏失败

游戏画面为 26×26 格、每格 16 像素的像素风格战场，敌人具备简单的追踪与随机转向 AI。
